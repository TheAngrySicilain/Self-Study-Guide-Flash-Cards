HTML Page Structure

html
root
↓
head
metadata, title, CSS link
↓
body
visible page content
<header> <nav> <main> <footer>

CSS Box Model

margin
border
padding
content

border-box keeps padding and borders inside the declared size.

* { box-sizing: border-box; }

Flexbox Axes

  • justify-content: main axis
  • align-items: cross axis
  • flex-direction: chooses the main axis

JavaScript Data Flow

original data
↓
filter
keep matching items
↓
map
transform each item
↓
new display data
items.filter(test).map(transform)

fetch Request Flow

pending Promise
↓
Response
↓
check response.ok
↓
await response.json()

HTTP 404 or 500 usually requires a manual response.ok check.

React Data Flow

parent state
↓ props
child UI
↑ callback
state update
setCount(prev => prev + 1)
